### Домашнее задание: сборка RPM-пакета и создание репозитория

#### Что нужно сделать?

 - создать свой RPM или взять готовый проект;
 - cоздать свой репозиторий и разместить там ранее собранный RPM;
 - реализовать это все либо в Vagrant, либо развернуть у себя через Nginx.

#### Описание работы

За основу выбрана облачная версия Fedora 44 с сайта разработчиков. Провайдером для машин выступает VirtualBox. 
Автоматизация пайплайна продолжена с прошлой задачи с применением методологии Infrastructure as Code. Дефолтные параметры виртуальной машины: 6 ядер CPU и 8Гб памяти. Для ускорения пайплайна лучше выделять как можно больше ресурсов хоста в Vagrantfile.

Рассматриваемые для воспроизведения сборки проекты: Mailcow, Redis, MMEX, PostgreSQL, Firefox, SQLite и Unbound. 
После нескольких итераций компиляции решено выбрать SQLite и дополнительно Unbound по следующим причинам:

1) Есть опыт работы с Unbound, его развёртыванием и настройкой
2) SQLite выбран для изучения упаковки C-библиотек и потенциальных конфликтов с системными библиотеками

Ключевые требования к пайплайну на основе Fedora Packaging Guidelines:
- Не включать системные библиотеки внутрь
- Разделять devel и runtime
- Проверять качество пакета через линтер
- Собирать пакеты через mock, чтобы не засорять систему

Архитектура пайплайна разделена на несколько этапов, что потребовало изучения концепции ролей и задач в Ansible. Всего четыре этапа:
- `environment` - подготовка сборочного окружения
- `build` - компиляция бинарных пакетов
- `validation` - установка пакетов и тестирование
- `repository` - создание локального репозитория

Схема:
 ```text
 📁 7_Управление пакетами
 ├── 📁 ansible/
 │   ├── 📁 group_vars/
 │   ├── 📁 roles/
 │   │   ├── 📁 environment/
 │   │   │   └── 📁 tasks/
 │   │   │       └── 📄 main.yml
 │   │   ├── 📁 build/
 │   │   │   └── 📁 tasks/
 │   │   │       └── 📄 main.yml
 │   │   ├── 📁 validation/
 │   │   │   └── 📁 tasks/
 │   │   │       ├── 📄 main.yml
 |   |   |       ├── 📄 sqlite_test.yml
 |   |   |       └── 📄 unbound_test.yml
 │   │   └── 📁 repository/
 │   │       └── 📁 tasks/
 │   │           └── 📄 main.yml
 │   └── 📄 site.yml
 └── 📁 artifacts/
     ├── 📁 sqlite/
     └── 📁 unbound/
 ```

В результате сборки получено 33 RPM-пакета:
- SQLite -18 RPM-пакетов.
- Unbound - 15 RPM-пакетов.

Из них в задачах Ansible описана установка только необходимых для работы базы данных и DNS-резолвера пакетов. Работоспособность подтверждается функциональными тестами:

- Для SQLite создаётся база и делается тестовый SQL-запрос + проверка целостности базы
- Для Unbound отправляется тестовый запрос домена

На завершающем этапе формируется локальный репозиторий с собранными пакетами.
